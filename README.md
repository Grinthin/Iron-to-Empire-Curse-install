Download the modpack file directly (the "raw" release asset) — do NOT use GitHub's green "Code" → "Download ZIP" button. That button zips the entire repository, including the modpack file itself, which is already a zip. You'd end up with a zip inside a zip, and importing the outer one won't work.

Go to the Releases page (link to your actual releases).
Under the latest release's Assets, click the modpack .zip file directly to download it. This is the correct file — skip straight to Installing below.
If you already downloaded via "Download ZIP" by mistake:

Extract that zip once.
Inside, you'll find the real modpack .zip file — that's the one to import, not the folder you just extracted it into.
Do NOT extract this inner zip too — Curseforge import it as-is
Don't forget to enable the Mythic mobs & quark resource pack. Adjust RAM allocation as required.
